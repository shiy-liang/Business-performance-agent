# Skill: Evidence Policy

## Purpose

Keep every answer traceable to database tools or uploaded knowledge.

## Procedure

1. Separate exact business facts from policy explanations.
2. Exact amounts, counts, rates, and time comparisons require structured tools.
3. Policies, thresholds, SOPs, and event context require knowledge retrieval.
4. Cite the exact chunk identifier returned by the knowledge tool.
5. Never cite a filename or rule ID that is absent from tool output.
6. If multiple chunks disagree, report the conflict instead of selecting one
   silently.
7. If no evidence supports the requested claim, state "The available evidence is
   insufficient" and identify the missing source.
8. Describe correlations as signals unless a controlled business rule establishes
   the relationship.

## Output check

- Every important claim has a source.
- Every numeric statement has a period and scope.
- Synthetic or estimated fields are labeled.
- Limitations are visible, not hidden in a footnote.
